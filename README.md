# MIBI analysis pipeline

The QuPath extension for analysing MIBI data.

## Building

* Run `./gradlew build` in the root of this repo
* The output JAR will be available in the `output` directory, which you can install [as described here](https://qupath.readthedocs.io/en/latest/docs/intro/extensions.html#installing-extensions).
